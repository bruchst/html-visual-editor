How it works

  • Paste HTML on the left, or click Open to load a file from disk.
  • Click Edit (top right) to enable in-place editing on the preview.
  • Click any text in the preview to change it. Changes sync back to the source code automatically.
  • Click Download to save the edited HTML as a new file.
  • Share compresses the HTML into a URL hash. Works for single-page snippets up to ~32 KB URL (about a 25 KB HTML file). Bigger? Use Download.
  • Drop a .html file onto the source pane to load it instantly.

Keyboard shortcuts

  • E   Toggle edit mode (when preview is focused)
  • Cmd/Ctrl + S   Download
  • Cmd/Ctrl + O   Open file

Edits run entirely in your browser. Nothing is uploaded. External images, fonts, and stylesheets referenced by relative paths won't load in the preview — they will work again once you download the file back into its folder.
